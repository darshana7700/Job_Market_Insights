# Job Market Insights

## 📌 Project Overview
This project analyzes job market data related to AI and technology roles using Microsoft Excel. The goal is to identify job trends, skills, salaries, locations, and other factors influencing the AI job market.

## 🎯 Objectives
- Analyze AI and technology job market trends
- Identify in-demand job roles and skills
- Compare salary trends
- Analyze job opportunities by location
- Create an interactive Excel dashboard
- Generate meaningful business insights

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Functions
- Data Cleaning
- Data Visualization
- Dashboard & KPI Analysis

## 📊 Project Features
- Data cleaning and preparation
- Job role analysis
- Salary analysis
- Skills analysis
- Location-wise analysis
- Interactive dashboard
- KPI cards and charts

## 💡 Key Insights
The dashboard helps understand:
- Which AI/technology roles are most in demand
- Which skills are frequently required
- Salary patterns across different roles
- Locations with higher job opportunities
- Overall trends in the AI job market
